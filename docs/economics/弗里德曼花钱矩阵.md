# 弗里德曼花钱矩阵

**弗里德曼花钱矩阵**（Friedman's four ways to spend money）是米尔顿·弗里德曼与罗斯·弗里德曼在《自由选择》（*Free to Choose*，1980）中提出的一个 2×2 分析框架。它按照两个问题划分支出：

1. 花的是谁的钱？
2. 钱花在谁身上？

这个框架用来说明：付款者、决策者和受益者是否为同一人，会影响其控制成本、了解需求和追求使用价值的激励。

## 四种花钱方式

|  | 花在自己身上 | 花在别人身上 |
| --- | --- | --- |
| **花自己的钱** | Ⅰ. 自己的钱，自己使用 | Ⅱ. 自己的钱，别人使用 |
| **花别人的钱** | Ⅲ. 别人的钱，自己使用 | Ⅳ. 别人的钱，别人使用 |

### Ⅰ. 花自己的钱，用在自己身上

例如用自己的收入购买日用品、电脑或住房。

- **控制成本的激励强**：支出直接减少自己的可支配收入；
- **追求价值的激励强**：自己承担产品质量和选择错误的后果；
- **需求信息通常较充分**：购买者最了解自己的偏好。

弗里德曼认为，这是四种情形中最容易兼顾节约和效用的一种。

### Ⅱ. 花自己的钱，用在别人身上

例如购买生日礼物或进行慈善捐赠。

- **控制成本的激励仍然较强**；
- **满足受益者需求的能力可能较弱**，因为付款者未必准确了解对方偏好；
- 付款者还可能追求体面、表达心意或自身声誉，而不只是受益者的效用。

直接赠送现金或让受益者自行选择，可以把一部分第二类支出转化为第一类支出。

### Ⅲ. 花别人的钱，用在自己身上

例如报销商务餐、使用公司差旅预算或享受由保险支付的服务。

- **追求自身利益的激励强**；
- **控制成本的激励较弱**，因为使用者不承担全部价格；
- 容易出现过度消费、规格升级或“反正可以报销”的行为。

这类问题与第三方支付、道德风险和委托—代理问题有关。报销上限、自付额和审核制度可以改变激励。

### Ⅳ. 花别人的钱，用在别人身上

例如公务人员使用公共预算采购社会服务，或企业采购部门替其他团队购买工具。

- 决策者既不直接承担全部成本，也不是最终使用者；
- 对成本和受益者偏好的直接激励都可能较弱；
- 容易受到信息层级、程序目标、部门利益和责任分散影响。

弗里德曼用这一象限批评政府支出，认为公共部门经常由一群人决定如何使用另一群人的钱，并为第三群人提供服务。

## 矩阵真正分析的是什么

这个矩阵不是在判断花钱者的品德，而是在比较制度中的激励和信息结构。

| 维度 | 关键问题 |
| --- | --- |
| 成本约束 | 决策者是否承担支出的机会成本？ |
| 受益一致 | 决策者能否直接获得选择带来的收益？ |
| 偏好信息 | 决策者是否了解最终使用者真正需要什么？ |
| 反馈机制 | 选择错误后，能否及时发现并纠正？ |
| 退出能力 | 使用者能否拒绝服务或更换提供者？ |
| 问责机制 | 浪费、寻租或低质量服务是否会产生后果？ |

付款者、选择者和使用者越分离，就越需要合同、监督、竞争和反馈来弥补天然激励不足。

## 典型应用

### 政府采购

纳税人提供资金，政府部门选择供应商，公众使用服务，三种角色相互分离。这不等于采购必然无效，但意味着预算透明、公开竞争、绩效评估和审计格外重要。

### 医疗保险

患者使用医疗服务，保险机构或政府承担大部分费用，医生又参与决定服务数量。它通常不是纯粹的第三或第四象限，而是多方激励交织的混合情形。

### 企业费用报销

员工是使用者，公司是付款者。费用标准、审批和个人便利之间如何平衡，会决定行政成本与浪费程度。

### 慈善项目

捐赠者出资，慈善机构配置资源，受助者接受服务。若受助者缺少表达偏好和退出的渠道，即使各方动机良好，也可能出现供需错配。

## 局限与常见误读

### “第一象限一定最有效”

不一定。个人会受信息不足、冲动消费、认知偏差和市场垄断影响；消费者也未必有能力判断医疗、教育或复杂金融产品的质量。

### “第四象限必然浪费”

不成立。公开预算、专业采购、竞争招标、独立审计、用户选择和民主问责都能加强成本与质量约束。大型机构还可能借助专业能力和规模采购降低成本。

### “矩阵证明政府支出越少越好”

矩阵本身不能得出这个结论。公共品、外部性、风险共担、基本权利和收入分配等问题，无法只靠私人交易解决。评价公共支出还要比较市场失灵、政府失灵、行政成本、公平和长期结果。

### “花别人的钱”真的与决策者无关

现实中很少存在完全分离。公务人员也可能是纳税人和公共服务使用者；企业经理要承担绩效压力；保险用户会通过保费间接承担成本。因此，四个象限更像连续光谱，而非互不相干的四个盒子。

## 制度设计启示

花钱矩阵最有用的地方，是帮助检查怎样让决策者同时关注成本和实际效果：

- 尽量让受益者拥有选择权，并建立真实、及时的反馈渠道；
- 明确预算责任，使决策者能够感受到机会成本；
- 公开价格、合同、服务质量和最终结果；
- 引入供应商竞争，同时防止垄断、串标和逐底竞争；
- 将绩效指标与受益者结果相联系，避免只考核花钱进度；
- 对第三方支付设置适当的共付、限额或事前审核，同时保护低收入和高风险群体；
- 定期评估项目，并允许低效方案退出或被替代。

更准确的总结是：**谁付款、谁选择、谁受益决定了天然激励；监督、竞争和问责决定了这些激励能否被修正。**
