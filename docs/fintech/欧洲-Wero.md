# 欧洲：Wero

Wero 是欧洲支付倡议（European Payments Initiative，EPI）推出的泛欧洲数字钱包和支付方案。它基于即时账户到账户（A2A）转账，是面向用户和商户的支付层，不是取代 SCT Inst、TIPS 或 RT1 的银行间清算系统。

## 使用方式

- 个人转账可使用手机号、邮箱地址或二维码，无需向对方提供 IBAN；
- 资金直接在关联的银行账户之间划转，通常在 10 秒内到账；
- 用户可通过参与银行的 App 或独立 Wero App 使用，具体入口取决于所在国家和开户银行；
- 在线付款时，需要商户结账页明确提供 Wero 选项。

## 覆盖范围

Wero 于 2024 年首先在比利时、法国和德国上线个人对个人（P2P）转账。在线商户付款已在这三个市场逐步推出，但是否可用仍取决于用户的银行和商户是否接入。

2026 年 9 月，卢森堡正将 Payconiq 分阶段迁移到 Wero；荷兰也已开始从 iDEAL 向 Wero 过渡。因此，Wero 并非已在整个欧洲普遍可用，实际使用前应查询开户银行和商户的最新支持情况。

## 与其他支付方式的区别

| 方案 | 定位 |
| --- | --- |
| Wero | 跨参与市场的钱包和用户支付品牌，支持个人转账并逐步扩展到电商和线下支付 |
| SCT Inst | SEPA 范围内的欧元即时转账规则方案 |
| TIPS、RT1 | 处理和结算即时转账的底层基础设施 |
| iDEAL、Payconiq | 荷兰和卢森堡的成熟本地支付方案，正分别向 Wero 过渡 |

## 风险提示

Wero 个人转账在授权后通常不能撤销。付款前应核对收款人姓名与联系方式；任何以“接收 Wero 付款”为由索要 IBAN、密码或验证码的消息都应视为可疑。
