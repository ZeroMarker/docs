# 卡组织介绍

卡组织（Card Network）是连接发卡机构、收单机构和商户的支付网络，负责制定交易规则，让银行卡能够跨银行、跨地区使用。常见的卡组织包括 Visa、Mastercard（万事达）、中国银联和 American Express（美国运通）。

可以把卡组织理解为银行卡支付的“交通网络”：银行等机构发行的卡通过这张网络，在不同商户完成支付。

## 支付链路中的参与方

| 参与方 | 主要职责 |
| --- | --- |
| 卡组织 | 建立支付网络，制定交易、安全、清算和争议处理规则 |
| 发卡机构 | 向用户发卡，管理账户或授信，决定是否批准交易 |
| 收单机构 | 为商户提供银行卡收款服务，处理交易并向商户结算 |
| 商户 | 提供商品或服务，接受持卡人付款 |
| 持卡人 | 使用银行卡消费 |

同一家机构可能承担多个角色。部分交易还涉及支付网关、支付处理商或聚合支付服务商，它们为商户或金融机构提供技术与接入服务。

## 一笔刷卡交易如何完成

以一笔典型的跨行消费为例，支付授权请求的路径是：

**持卡人付款 → 商户的收单机构 → 卡组织网络 → 发卡机构审批**

审批结果沿链路返回商户，决定这笔支付能否继续。之后还需要完成清算和资金结算：

1. **授权**：发卡机构核验账户状态、可用余额或额度及风险，批准或拒绝交易。
2. **清算**：依据提交的交易记录计算各参与机构应收、应付的金额和费用。
3. **结算**：依据清算结果完成机构间资金交收，并按收单服务约定向商户入账。

卡组织提供网络和规则支持；用户账户扣款、信用额度管理等通常由发卡机构负责。支付终端显示“成功”通常表示授权获批，并不意味着商户已经收到结算资金。具体处理顺序和时点取决于网络及交易类型。

## 常见卡组织

日常所说的“卡组织”常把运营机构、卡品牌和卡支付方案（Card Scheme）放在一起讨论。下列条目既包含跨境经营的国际网络，也包含主要服务本地市场的卡支付方案；它们并不都对应一家独立公司。

### 国际卡组织与品牌

| 卡组织 | 业务模式与特点 |
| --- | --- |
| Visa | 以支付网络服务为核心，通常不直接向消费者发卡或提供贷款，与银行等发卡机构合作 |
| Mastercard（万事达） | 以支付网络服务为核心，连接发卡和收单机构，并提供相关技术服务 |
| 中国银联 | 提供银行卡跨行交易转接、清算及相关支付服务 |
| American Express（美国运通） | 既经营支付网络，也在部分市场直接承担发卡、收单等业务，并与合作机构开展业务 |
| [JCB](https://www.global.jcb/en/about-us/what-we-do/index.html) | 源自日本的国际支付品牌，与金融机构合作提供信用卡、借记卡和预付卡，并通过自有受理网络及网络合作拓展海外使用 |
| [Discover Network](https://www.discoverglobalnetwork.com/) | 源自美国的支付网络，通过 Discover、大来、PULSE 及网络联盟伙伴拓展支付与取现受理 |
| [Diners Club International（大来）](https://www.dinersclub.com/about-us/) | 国际卡品牌，通过当地发卡合作伙伴提供卡产品；与 Discover Network、PULSE 同属官方介绍的全球网络体系，不能简单视作与 Discover 完全独立的网络 |

JCB、Discover 等网络会通过合作扩大受理范围。例如，JCB 官方说明其在美国通过 Discover Network 合作受理。这类安排针对具体市场和商户，并不代表合作双方在全球所有地点都可以无条件互用。

### 本地及区域性卡支付方案

本地网络通常围绕本国银行账户、借记卡和商户受理建立，也可能通过国际合作支持境外使用。“本地”描述其业务基础，不代表一定只能在境内使用。

| 卡组织、品牌或方案 | 主要市场 | 定位与特点 |
| --- | --- | --- |
| [RuPay](https://www.npci.org.in/PDF/npci/rupay/Product-Booklet.pdf) | 印度 | NPCI 建立的本土卡支付方案；境外受理通过国际网络合作扩展，需看具体卡产品 |
| [BC Card（비씨카드）](https://www.bccard.com/company/en/business/) | 韩国 | 兼具本地卡品牌与支付处理平台角色，为成员银行等机构提供授权转接、收单、清算和结算服务；BC Global 通过境外合作网络扩展受理 |
| [Cartes Bancaires（CB）](https://www.cartes-bancaires.com/) | 法国 | 法国本地银行卡及移动支付方案；CB 是支付方案标识，不是某一家发卡银行的名称 |
| [girocard](https://www.girocard.eu/) | 德国 | 德国本地卡支付体系，广泛用于商户日常收款；其受理标识应与卡上的其他网络标识分别识别 |
| [Bancontact](https://www.bancontact.com/en/consumer) | 比利时 | 本地支付品牌，提供卡片及移动支付方式；介绍卡组织时应区分其卡业务与 App、二维码等使用入口 |
| [eftpos](https://www.auspayplus.com.au/solutions/eftpos-for-consumers) | 澳大利亚 | 澳大利亚本地借记卡网络，属于 Australian Payments Plus 的支付方案；小写品牌名 eftpos 与泛指支付终端的 EFTPOS 概念应区分 |
| [Interac Debit](https://www.interac.ca/en/content/business/who-are-we-learn-how-interac-powers-daily-transactions-for-canadians/) | 加拿大 | Interac 旗下的借记支付网络；与同品牌下用于转账的 Interac e-Transfer 是不同服务 |
| [mada](https://www.sama.gov.sa/en-US/payment/Pages/mada.aspx) | 沙特阿拉伯 | 沙特本地支付系统，连接本地银行卡与商户受理、ATM 等基础设施 |
| [TROY](https://www.troyodeme.com/en/about-troy/about-us) | 土耳其 | 土耳其本土卡支付体系；带有相应国际支付方案标识的卡，可按合作安排在境外使用 |
| [Elo](https://www.elo.com.br/sobre-elo/) | 巴西 | 巴西本土卡品牌，提供基于本地技术与支付需求的产品和服务 |
| [PULSE](https://www.pulsenetwork.com/public/about-pulse/) | 美国为主 | 借记支付及 ATM 网络，为 Discover、大来等卡提供相关 ATM 受理能力；与 Discover、大来存在同一网络体系内的关系 |

以上为代表性条目，并非全球卡支付方案的完整名单。各网络的覆盖、合作关系和产品能力会变化，实际使用应核对发卡机构和网络官方资料。

### 韩国 BC Card 与 BC Global

**BC Card** 不只是卡面上的品牌标识，也为成员银行及其他客户机构提供银行卡处理服务。其业务包括把商户的授权请求转送到相应发卡机构，以及处理商户交易数据、清算和结算。因此，理解韩国银行卡体系时，需要同时考虑它的本地受理网络与后台处理平台角色。参见 [BC Card 官方业务介绍](https://www.bccard.com/company/en/business/)。

**BC Global** 则是 BC Card 的境内外通用卡品牌，境外服务依靠网络合作。官方说明列举了美国 Discover、日本 JCB、中国银联（页面写作 UPI）及 Diners Club 的合作受理网络。这并不表示所有带 BC 标识的卡都具备相同的境外能力；应区分具体卡产品，并查看卡背面的合作网络标识、发卡机构说明及商户受理条件。参见 [BC Global 官方境外使用说明](https://www.bccard.com/app/card/ContentsLinkActn.do?pgm_id=ind0166)。

### 一张卡为什么会有多个网络标识

同一张卡可能同时支持本地方案与国际方案，这通常称为**共标卡（Co-badged Card）**或多网络卡。例如，澳大利亚的借记卡可以同时支持 eftpos 和国际卡网络，土耳其的部分 TROY 卡通过国际方案合作支持境外交易。

这意味着同一张卡可能存在不同的交易路由。实际走哪条网络，取决于商户受理能力、发卡与收单配置及适用的路由规则。共标也不等于银行与航空公司、零售商推出的“联名卡”：前者涉及支付网络，后者主要涉及品牌合作与权益安排。参见 [eftpos 官方支持说明](https://www.auspayplus.com.au/solutions/eftpos-support)及 [TROY 官方介绍](https://www.troyodeme.com/en/about-troy/about-us)。

## 卡组织如何收费

卡组织主要通过交易处理、网络服务、跨境交易及其他相关服务收费。商户支付的收款手续费通常涉及发卡机构、卡组织和收单机构等参与方，并非全部归卡组织。具体费用可能打包报价，也可能分项展示；费率取决于市场、卡种、交易方式及合同安排。

## 与信用卡、电子钱包、即时支付的区别

- **借记卡与信用卡**是卡产品类型，主要区别在于使用账户资金还是信用额度。同一卡组织网络可以支持多种卡产品。
- **Apple Pay 等电子钱包**是用户使用卡片或其他支付工具的入口。钱包中的银行卡交易仍可能通过相应卡组织网络处理。
- **即时支付系统**通常直接连接银行或支付机构账户，与银行卡网络属于不同支付路径。参见[各国即时支付方式](index.md)。

卡面上的 Visa、Mastercard 或银联标识，主要说明这张卡接入哪套支付网络。它本身不代表信用卡等级、额度或权益；这些还需要查看发卡机构的具体产品条款。商户是否受理，也取决于当地收单接入和具体交易条件。
