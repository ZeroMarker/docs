# 卡组织介绍

卡组织（Card Network）是连接发卡机构、收单机构和商户的支付网络，负责制定交易规则，让银行卡能够跨银行、跨地区使用。常见的卡组织包括 Visa、Mastercard（万事达）、中国银联和 American Express（美国运通）。

可以把卡组织理解为银行卡支付的“交通网络”：银行等机构发行的卡通过这张网络，在不同商户完成支付。

## 支付链路中的参与方

| 参与方 | 主要职责 |
| --- | --- |
| 卡组织 | 建立支付网络，制定交易、安全、清算和争议处理规则 |
| 发卡机构 | 向用户发卡，管理账户或授信，决定是否批准交易 |
| 收单机构 | 为商户提供银行卡收款服务，处理交易并向商户结算 |
| 商户 | 提供商品或服务，接受持卡人付款 |
| 持卡人 | 使用银行卡消费 |

同一家机构可能承担多个角色。部分交易还涉及支付网关、支付处理商或聚合支付服务商，它们为商户或金融机构提供技术与接入服务。

## 一笔刷卡交易如何完成

以一笔典型的跨行消费为例，支付授权请求的路径是：

**持卡人付款 → 商户的收单机构 → 卡组织网络 → 发卡机构审批**

审批结果沿链路返回商户，决定这笔支付能否继续。之后还需要完成清算和资金结算：

1. **授权**：发卡机构核验账户状态、可用余额或额度及风险，批准或拒绝交易。
2. **清算**：依据提交的交易记录计算各参与机构应收、应付的金额和费用。
3. **结算**：依据清算结果完成机构间资金交收，并按收单服务约定向商户入账。

卡组织提供网络和规则支持；用户账户扣款、信用额度管理等通常由发卡机构负责。支付终端显示“成功”通常表示授权获批，并不意味着商户已经收到结算资金。具体处理顺序和时点取决于网络及交易类型。

## 常见卡组织

| 卡组织 | 业务模式与特点 |
| --- | --- |
| Visa | 以支付网络服务为核心，通常不直接向消费者发卡或提供贷款，与银行等发卡机构合作 |
| Mastercard（万事达） | 以支付网络服务为核心，连接发卡和收单机构，并提供相关技术服务 |
| 中国银联 | 提供银行卡跨行交易转接、清算及相关支付服务 |
| American Express（美国运通） | 既经营支付网络，也在部分市场直接承担发卡、收单等业务，并与合作机构开展业务 |

## 卡组织如何收费

卡组织主要通过交易处理、网络服务、跨境交易及其他相关服务收费。商户支付的收款手续费通常涉及发卡机构、卡组织和收单机构等参与方，并非全部归卡组织。具体费用可能打包报价，也可能分项展示；费率取决于市场、卡种、交易方式及合同安排。

## 与信用卡、电子钱包、即时支付的区别

- **借记卡与信用卡**是卡产品类型，主要区别在于使用账户资金还是信用额度。同一卡组织网络可以支持多种卡产品。
- **Apple Pay 等电子钱包**是用户使用卡片或其他支付工具的入口。钱包中的银行卡交易仍可能通过相应卡组织网络处理。
- **即时支付系统**通常直接连接银行或支付机构账户，与银行卡网络属于不同支付路径。参见[各国即时支付方式](index.md)。

卡面上的 Visa、Mastercard 或银联标识，主要说明这张卡接入哪套支付网络。它本身不代表信用卡等级、额度或权益；这些还需要查看发卡机构的具体产品条款。商户是否受理，也取决于当地收单接入和具体交易条件。
