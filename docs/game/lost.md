不要从来源不明的 APK 网站下载安装包。第三方重新打包的应用可能被植入恶意代码，也可能包含未经准确标注的成人、暴力或涉及未成年角色的内容。安装前至少应确认开发者身份、包名、签名、权限和可信发行来源。
