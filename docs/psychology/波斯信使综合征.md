# 波斯信使综合征

**波斯信使综合征**（Persian Messenger Syndrome）指人们因厌恶坏消息，而迁怒或惩罚传递消息的人。它也常被概括为“射杀信使”（shooting the messenger）。

这个名称不是正式的医学或精神科诊断，而是查理·芒格用于说明认知偏差和组织行为问题的通俗说法。

## 名称由来

芒格在《人类误判心理学》（*The Psychology of Human Misjudgment*）中提到，古代波斯的信使可能因如实报告战败而被杀；在现代组织中，传递坏消息虽然通常不会招致如此极端的后果，却可能令人失去赏识、晋升机会或同事支持。

“处死败讯信使”的故事更适合作为寓言理解，不宜在缺少可靠史料的情况下当作确定的古代波斯制度。这个概念的价值主要在于揭示一种至今仍然存在的行为模式。

## 心理机制

波斯信使综合征包含相互强化的两面：

1. **接收者迁怒信使**：坏消息引发焦虑、失望或失控感，这些负面感受又通过简单联想附着在传信者身上。即使传信者与坏结果无关，也可能被认为不讨喜，甚至被怀疑别有用心。
2. **传信者隐瞒坏消息**：人们预期接收者会不悦，因而延迟、淡化或拒绝传递坏消息。这与传播研究中的 **MUM 效应**（对不良信息保持沉默）相近。

2019 年发表于 *Journal of Experimental Psychology: General* 的一项研究通过 11 个实验发现，人们会降低对无辜坏消息传递者的好感；当坏消息出乎意料或难以解释时，这种倾向可能更强。早期关于 MUM 效应的研究则显示，相比好消息，人们更不愿意主动、完整地传递坏消息。

## 在组织中的表现

常见表现包括：

- 员工报告风险后，首先被追问“为什么现在才发现”，而不是讨论如何处理；
- 管理者公开要求坦诚，实际却对提出异议者冷淡、贬损或边缘化；
- 汇报材料逐级上报时，风险描述不断被弱化；
- 项目长期“进展顺利”，问题却总在最后一刻集中暴露；
- 数据、审计或媒体因揭示问题，反而被当作问题本身。

其典型链条是：

> 坏消息引发惩罚 → 成员产生预期恐惧 → 信息被隐瞒或美化 → 决策者脱离现实 → 问题扩大 → 惩罚进一步加重

因此，组织里“没有坏消息”并不一定代表运行良好，也可能说明坏消息已经无法安全地到达决策者。

## 如何避免

### 对管理者

- **控制第一反应**：先感谢报告者，再核实事实和评估影响。
- **区分信息与责任**：报告问题不等于制造问题，追责也不应先于止损。
- **奖励尽早暴露风险**：把及时预警视为贡献，并建立清晰、稳定的正向反馈。
- **主动寻找反证**：定期询问“最可能失败的地方是什么”“有哪些信息与当前判断冲突”。
- **提供安全渠道**：设置匿名反馈、越级汇报和反报复机制。

### 对信息传递者

- 将事实、判断和建议分开表达；
- 说明信息来源、可信度与未知部分；
- 尽早报告，不因等待完美证据而错过处理窗口；
- 在指出风险的同时，提供可执行的下一步方案。

## 相关概念

| 概念 | 侧重点 |
| --- | --- |
| 射杀信使效应 | 接收者因坏消息而贬低或排斥传信者 |
| MUM 效应 | 传递者不愿转达对接收者不利的信息 |
| 确认偏误 | 人们偏好支持既有信念的信息 |
| 组织沉默 | 成员因恐惧、无力感等原因不表达意见 |
| 心理安全感 | 成员相信提出问题或承认错误不会遭到羞辱、惩罚 |
